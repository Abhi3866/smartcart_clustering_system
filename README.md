# smartcart_clustering_system
SmartCart Clustering System is a customer segmentation project that uses unsupervised machine learning techniques to identify meaningful customer groups based on purchasing behaviour, demographics, website activity, and customer engagement.

The project aims to discover hidden patterns in customer data using clustering algorithms, helping businesses understand customer behaviour, improve marketing strategies, identify high-value customers, and support customer retention.

**Key Highlights:**
- Customer data analysis and preprocessing
- Exploratory Data Analysis (EDA)
- Feature scaling and data preparation
- Customer segmentation using clustering algorithms
- Identification of customer behaviour patterns
- Data visualization and cluster analysis

**Technologies Used:** Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, and Jupyter Notebook.
